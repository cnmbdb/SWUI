The native layer

Same state machine. Native implementation.

The source uses SwiftUI data, SF Symbols, matched geometry, and one critically damped spring. There is no web component pretending to be the app.

Built for iOS 17+
ActionSplitView.swift 
enum ActionPhase: CaseIterable {
    case discover, qr, payment

    var actions: [ActionItem] {
        switch self {
        case .discover:
            return [.contact, .scan, .close]
        case .qr:
            return [.close, .contact, .myQR]
        case .payment:
            return [.pay, .request]
        }
    }
}

// The current presentation value stays in the conversation.
withAnimation(.spring(
    response: 0.52,
    dampingFraction: 0.88
)) {
    phase = nextPhase
}

The motion model

Make the change feel inevitable.

Every transition answers a question: what moved, why did it move, and can the user change their mind halfway through?
